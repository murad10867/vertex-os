# Security Policy

Vertex OS is a static browser project.

Security measures:
- HTTPS enforcement on GitHub Pages.
- Restrictive Content Security Policy.
- No inline JavaScript.
- External links are hardened with noopener/noreferrer.
- Unsafe URL schemes are blocked.
- The page blocks unauthorized framing.

Never commit passwords, private API keys, payment secrets, GitHub tokens, Supabase service-role keys, or other credentials.
